# Agent handoffs

Cursor chats do not talk to each other. Use **these templates + git + `SESSION_STATE.md`** as the shared bus.

| Document | When |
|----------|------|
| [BRIEF_FOR_JOAN.md](BRIEF_FOR_JOAN.md) | **Before Iteration 8+:** architect brief for scale, UX sequencing, proposed iterations 8–12 (read with builder handoff). |
| [HANDOFF_TO_BUILDER.md](HANDOFF_TO_BUILDER.md) | Start a **new implementation** chat; fill and paste (or `@` the file). **Iterations 25–28** + post-27/post-28 hardening shipped; **next: Iteration 29** (run economics). |
| [HANDOFF_TO_ARCHITECT.md](HANDOFF_TO_ARCHITECT.md) | End of slice; paste into **architect** chat for review / Iteration N+1 planning. |
| [ARCHITECT_SIGNOFF_CHECKLIST_ITER10_11.md](ARCHITECT_SIGNOFF_CHECKLIST_ITER10_11.md) | Use before Iteration 10–11 handback; Joan self-checks and reports pass/fail in architect handoff. |

Also use `docs/reviews/REVIEW_REQUEST_iteration-*.md` for external reviewers (e.g. Opus) the same way: **human-mediated** paste and file writes.
