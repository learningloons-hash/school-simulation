| [HANDOFF_TO_BUILDER.md](HANDOFF_TO_BUILDER.md) | Start a **new implementation** chat; fill and paste (or `@` the file). Await next GM arc handoff. |
| [HANDOFF_TO_ARCHITECT.md](HANDOFF_TO_ARCHITECT.md) | End of slice; paste into **architect** chat for review / Iteration N+1 planning. |
| [ARCHITECT_SIGNOFF_CHECKLIST_ITER10_11.md](ARCHITECT_SIGNOFF_CHECKLIST_ITER10_11.md) | Use before Iteration 10–11 handback; Joan self-checks and reports pass/fail in architect handoff. |
